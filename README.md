# Hackatouille

Hackatouille is a small game created during **Global Game Jam Hamar 2026**.
The project was built under a strict time limit, focusing on rapid prototyping, experimentation, and teamwork.

The goal of the project was to design and implement a playable game within the limited timeframe of the event.

---

## Game Concept

Hackatouille is a fast-paced experimental game where the player navigates challenges while interacting with the environment and solving gameplay objectives.

The project emphasizes quick iteration and creative problem solving rather than long-term polish, which is typical for game jam projects.

```

```

2. Open the project in **Unity Editor**

3. Load the main scene

4. Press **Play** to start the game.
